# 🏡 Willowbrook Homepage — Solo Project Replacement  
*A multi‑section homepage introducing the fictional town of Willowbrook.*

---

## 🎯 Project Goal  
Create a multi‑section homepage for **Willowbrook**, featuring a flexbox header, gradient background, hover‑interactive “places,” a facts table, audio/video, and a footer — all styled using the techniques you’ve learned.

---

## 📐 Requirements  
Every requirement begins with a Guided Link so you can explore any part further if you want.

---

# 🧱 Structure Requirements

### Header  
- **Header container** — A full‑width header at the top of the page.  
- **Flexbox header** — The header must be a flex container.  
- **Header title** — Must contain exactly this text:  
  **“Welcome to Willowbrook”**  
- **Header subtitle** — Must contain exactly this text:  
  **“A place full of stories, nature, and community.”**  
- **Header alignment** — Use align‑items to vertically center header content.  
- **Header direction** — Use flex‑direction to control layout of title + subtitle.  

---

### Main Section: “About Willowbrook”  
- **Section heading** — Must contain exactly this text:  
  **“About Willowbrook”**  
- **Paragraph** — Must contain exactly this text:  
  **“Willowbrook is known for its peaceful forests, friendly locals, and rich cultural heritage. It’s a town where tradition meets modern life, creating a warm and welcoming atmosphere for visitors and residents alike.”**  
- **Text emphasis** — Use `<em>` and `<strong>` at least once inside this section.

---

### Featured Places Section  
This section replaces images with styled divs.

- **Section heading** — Must contain exactly this text:  
  **“Places You Should Visit”**  
- **Place cards** — Create **four** “place cards,” each represented by a styled `<div>` instead of an `<img>`.  
- Each place card must contain a title + description using these exact texts:

#### Place 1  
- Title: **“Willowbrook Forest Trail”**  
- Description: **“A peaceful walking path surrounded by tall trees, wildlife, and fresh air.”**

#### Place 2  
- Title: **“Maple Street Market”**  
- Description: **“A lively market filled with handmade goods, fresh produce, and local treats.”**

#### Place 3  
- Title: **“Lakeside Boardwalk”**  
- Description: **“A scenic lakeside walkway perfect for sunsets, photos, and relaxing afternoons.”**

#### Place 4  
- Title: **“Willowbrook Heritage Museum”**  
- Description: **“Explore the town’s history through interactive exhibits and preserved artifacts.”**

- **Hover effects** — Each place card must visually change on hover.  
- **Flexbox layout** — The place cards must be arranged using flexbox.  

---

# 🎨 Styling Requirements

- **Background gradient** — The entire page must use a gradient background.  
- **Header styling** — Add basic header styling (padding, background color, etc.).  
- **Color palette** — Use a warm, nature‑inspired palette (greens, browns, soft yellows).  
- **Text‑shadow** — Apply text‑shadow to the main header title.  
- **Flexbox alignment** — Use align‑items and justify‑content where appropriate.  
- **Hover effects** — Place cards must change appearance on hover.  
- **Utility classes** — Use at least one utility class (e.g., `.text-center`, `.shadow-sm`, `.mt-2`).  
- **IDs** — Use at least one ID for styling.  
- **Google Fonts** — Use the Google Font:  
  **“Nunito”** (weights 400 + 700).  
- **Margin & padding shorthand** — Use shorthand syntax at least twice.
